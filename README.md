## 🌐 What Makes My Work Different

### SEO/GEO/AEO Engineering

I don't just build websites — I build **AI-discoverable knowledge systems**:

- **369 static pages** with full Schema.org entity graph
- **8 JSON-LD schema types** (Organization, Service, BlogPosting, HowTo, DefinedTerm, FAQPage, SpeakableSpecification, BreadcrumbList)
- **llms.txt** + llms-full.txt for ChatGPT/Gemini/Perplexity discovery
- **Bilingual architecture** (Arabic + English) with proper hreflang, canonical, and locale-aware structured data
- **Entity Authority** system: `about`, `mentions`, `knowsAbout`, `isPartOf`, `hasPart` cross-linking every page
- **14 AI crawlers** explicitly allowed in robots.txt (GPTBot, ClaudeBot, PerplexityBot, etc.)

> This architecture is built to rank not just in Google, but to be **cited by AI assistants** when users ask "best software company in Yemen?"

### Full-Stack Delivery

From SCADA sensor firmware to React Native mobile apps to Next.js marketing sites — I deliver the complete stack without handoffs.
